## 4. 方法论备忘

1. **传输层失败先分诊三种死法**（掐流 / 流停滞 / 整请求超时）再对症——前两种插件管，第三种是配置病；账本的失败码+时间间隔分类是分诊依据。
2. **一切以磁盘为准**：会话事件流（多帧 zstd）与账本 JSONL 是唯一真源，UI 状态仅作参考。
3. **源码级根因优先**：agent-loop 的失败语义与 goal-round-driver 的 disarm 行为均从安装包源码核实，不猜 API。
4. **无 BOM 的 UTF-8 .ps1 编辑后必须复检首三字节**（一次 BOM 丢失导致 E2E 套件 0/15 的教训）。
5. 化石数据（733/46 连败）是内置无限重试时代的产物——它们证明"不干预"的上限代价。
